# Age-related dynamics of DNA co-methylation modules in humans

Code accompanying the manuscript:

**"Age-related dynamics of DNA co-methylation modules in humans"**

This repository contains R, Bash and SLURM scripts used to investigate age-related changes in DNA co-methylation networks using whole-blood DNA methylation data from Generation Scotland.

The analyses examine age-associated changes in pairwise CpG correlations and co-methylation networks as well as sex-stratified age-associated network dynamics, using a large cohort of human DNA methylation data from the Generation Scotland cohort.

## Repository structure

### `analysis/01_wgcna_combined_sex/`

Scripts for:
- DNA methylation preprocessing and residualisation
- Construction of reference co-methylation networks using WGCNA
- Module preservation across eight age groups
- Module characterisation and functional enrichment
- Downstream associations and visualisation

### `analysis/02_wgcna_within_sex/`

Scripts for:
- Sex-stratified DNA methylation network analyses
- Module preservation and age-related network dynamics
- Downstream characterisation and visualisation

### `analysis/03_pairwise_correlations/`

Scripts for:
- Pairwise CpG correlation analyses
- Heteroskedasticity testing
- Correlation and covariance estimation
- Correlation decay with genomic distance
- Identification and characterisation of stable and changing CpG pairs
- Downstream visualisation

### `data/`

Reference genomic annotations and external datasets used for downstream analyses.

### `results/`

Derived analysis results used to reproduce downstream analyses and manuscript figures.

### `figures/`

Destination for figures generated by the analysis scripts.

## Data availability

The derived analysis results and reference datasets are archived separately on Figshare.

The Figshare dataset contains four archives:

1. `01_wgcna_combined_sex.tar.gz`
2. `02_wgcna_within_sex.tar.gz`
3. `03_pairwise_correlations.tar.gz`
4. `reference_data.tar.gz`

Individual-level DNA methylation measurements and participant metadata from Generation Scotland are not distributed through this repository. Access to the underlying data is subject to Generation Scotland's data-access procedures.

## Running the analyses

After obtaining the Figshare archives, extract the reference data into the repository root:

```bash
tar -xzf reference_data.tar.gz
```

## Extract derived results

```bash
mkdir -p results

tar -xzf 01_wgcna_combined_sex.tar.gz -C results/
tar -xzf 02_wgcna_within_sex.tar.gz -C results/
tar -xzf 03_pairwise_correlations.tar.gz -C results/
```

The scripts under `analysis/` can then be used to reproduce downstream analyses and figures, subject to the required R packages, software dependencies and computing environment.

Analyses that begin with individual-level Generation Scotland data require authorised access and cannot be reproduced solely from the deposited derived results.

## Software

Analyses were conducted primarily in R. Specialised bioinformatics software used includes GCTA, WGCNA and MAGMA, together with packages for DNA methylation analysis, genomic annotation, functional enrichment, statistical modelling, and visualisation.

Data processing and computationally intensive analyses were performed on high-performance computing (HPC) infrastructure using Bash and the SLURM workload manager. Downstream statistical analyses and visualisation were primarily conducted in R.

## Notes
